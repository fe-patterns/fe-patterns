# About

fe-patterns is a catalog of frontend **Patterns** — reusable solutions to
recurring problems — together with the Libraries that implement them, the Skills
that apply them, and the Blog posts that explore them.

A Pattern is more than a definition: it ships a Skill that applies, assesses, and
refactors code toward it, and Guards that keep that code conformant over time.
The aim is to **help humans and AI agents produce high-quality
code, fast.**

## Goals

Every Pattern earns its place by advancing at least one Goal — a quality of good
code that justifies it. The Goals are these:

<ul class="entry-list">
	<li>
		<span style="font-weight:600">Testability</span>
		<div class="meta">
			Behaviour can be pinned down and verified in isolation.
		</div>
	</li>
	<li>
		<span style="font-weight:600">Maintainability</span>
		<div class="meta">
			Change stays cheap as the code and the team grow.
		</div>
	</li>
	<li>
		<span style="font-weight:600">Comprehensibility</span>
		<div class="meta">
			Minimal cognitive load — a reader (human or AI) can hold the piece in their head.
		</div>
	</li>
</ul>
